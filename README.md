# E-Commerce Sales Analytics Dashboard

## Project Overview

This project analyzes an E-Commerce Superstore dataset using Excel, SQL, Python, and Power BI.

The goal is to identify sales trends, profit performance, top customers, top products, and business insights through interactive dashboards.

---

##  Tools Used

- Microsoft Excel
- MySQL
- Python (Pandas, Matplotlib)
- Power BI
- VS Code
