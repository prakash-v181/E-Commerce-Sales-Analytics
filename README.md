# E-Commerce Sales Analytics Dashboard

## Project Overview

This project analyzes the E-Commerce Superstore dataset using Excel, MySQL, Python, and Power BI.

The objective of this project is to analyze sales performance, customer behavior, product performance, and profit trends using data analysis and visualization techniques.

- Technology category generated the highest sales.
- West region generated the highest profit.
- Top customers contributed significantly to total sales.
- Product sales varied across different categories.

## Installation

Clone the repository

```bash
git clone https://github.com/prakash-v181/E-Commerce-Sales-Analytics.git
```

Open the project folder

```bash
cd E-Commerce-Sales-Analytics
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run Jupyter Notebook

```bash
jupyter notebook
```

Open

```text
Python/analysis.ipynb
```
